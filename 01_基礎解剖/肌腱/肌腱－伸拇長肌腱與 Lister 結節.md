# 肌腱－伸拇長肌腱與 Lister 結節

## 基本資料

- 起點／肌腹來源：尺骨後面中段與骨間膜後面。
- 止點：拇指遠端指骨基底背側。
- 主要功能：伸展拇指 IP 關節，協助 MCP 與 CMC 伸展。
- 神經支配：後骨間神經。

## 解剖位置與走向

通過第三伸肌腱室，在 Lister 結節尺側轉折後斜向拇指背側。

## 觸診方式

手掌平放，請個案把拇指抬離桌面，沿 Lister 結節至拇指背側觀察輕觸；急性痛不反覆抗阻。

## 功能與負荷特性

肌腱在轉折處滑動並傳遞拇指伸展力量；握持、放開、球拍控制與精細操作皆需要。

## 常見傷害

橈骨遠端骨折後延遲斷裂、銳傷、腱鞘炎、固定物刺激與類風濕相關斷裂。

## 評估重點

比較主被動拇指 IP 伸展、tabletop lift-off、tenodesis、肌腱連續性與後骨間神經其他肌群。

## 臨床意義

伸拇短肌可造成部分 MCP 伸展，不能只看外觀；IP 主動伸展喪失需快速辨識。
