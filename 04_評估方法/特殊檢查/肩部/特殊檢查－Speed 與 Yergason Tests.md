# 特殊檢查－Speed 與 Yergason Tests

## 臨床意義

兩測試用於誘發肱二頭肌長頭／上盂唇相關症狀，但診斷效能有限；結果只能修正臨床機率，不能作為確診或排除工具。

## 操作步驟

### Speed Test
1. 坐／站姿，肩約 90°屈曲、肘伸直、前臂旋後。
2. 檢查者向下施力，受測者維持位置；避免突然大力。

### Yergason Test
1. 肘約 90°屈曲、前臂旋前靠近軀幹。
2. 受測者對抗旋後並輕度外旋；記錄前肩／結節間溝症狀或喀動感。

## 判讀

- 陽性以再現熟悉的結節間溝／前肩症狀為主，不只是任何疼痛。
- 一項手術對照研究：Speed 敏感度 32%、特異度 75%；Yergason 敏感度 43%、特異度 79%，變化幅度有限且受族群影響。
- 必須整合病史、其他負荷測試、頸椎／旋轉肌袖評估與必要影像。

## 禁忌／紅旗

疑似骨折、脫臼、急性斷裂或劇烈疼痛時不做。避免將陰性結果當成排除盂唇或長頭肌腱病變。
