# 特殊檢查－Hip Log Roll Test

## 臨床意義

Hip Log Roll Test 以低幅度被動旋轉觀察髖關節疼痛、鬆弛與左右差異，可作為關節內或關節囊問題的線索。它是整體評估的一部分，不是特定病灶的確診工具。

## 評估／操作步驟

1. 個案仰躺、下肢放鬆，雙側髖膝伸直。
2. 檢查者托住小腿或足踝，使整條下肢如圓木般緩慢內外旋。
3. 先從無症狀側開始，使用小幅、無強迫的動作。
4. 記錄疼痛位置、活動終感、外旋角度與左右差異。

## 判讀

深層腹股溝痛、明顯外旋增加或異常柔軟終感可提高對關節內病變、關節囊鬆弛或創傷的疑慮，但不能區分骨折、唇傷、感染或其他病因。結果需與機轉、承重、活動度、神經血管檢查及影像共同判讀。

## 禁忌／紅旗

- 懷疑骨折、脫臼、感染或高能量創傷時，不反覆或強力施測。
- 出現劇痛、痙攣、神經症狀或阻力突變立即停止。
- 陰性結果不能排除隱匿性骨折或關節內病變。
