# 特殊檢查－Cozen Test

## 檢查目的

Cozen Test 以抗阻腕伸、橈偏與握拳負荷共同伸肌腱，協助評估外側肘肌腱病變。它是症狀重現測試，不是影像或組織學確診。

## 操作方法

1. 個案坐姿，肘微屈或依紀錄姿勢固定，前臂旋前。
2. 個案握拳、腕背伸並輕度橈偏。
3. 操作者固定前臂，對第二、三掌骨區施向掌屈與尺偏方向阻力。
4. 記錄外上髁附近是否出現熟悉疼痛、力量與代償。

- 個案姿勢：依上述操作內容與個案耐受度設定。
- 操作者位置：依上述操作內容設定並確保可穩定控制。
- 固定位置：固定近端並避免非目標動作代償。
- 施力方向：依上述操作步驟施力。
- 比較方式：必要時與健側比較，並記錄疼痛、防禦與終末感。

## 陽性結果

重現外上髁／共同伸肌腱熟悉疼痛為陽性。2021 系統性回顧認為 Cozen test 與握力可能有較高診斷準確度，但研究數少、方法與參考標準異質，不能只用一個陽性結果確診。

### 禁忌與錯誤

疑骨折／脫臼、急性嚴重疼痛或術後禁阻力時不做。常見錯誤包括姿勢未固定、只問「痛不痛」未確認位置與熟悉度，以及忽略頸／橈神經來源。
