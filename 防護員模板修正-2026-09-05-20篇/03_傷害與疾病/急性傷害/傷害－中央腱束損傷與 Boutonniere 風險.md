# 傷害－中央腱束損傷與 Boutonniere 風險

## 定義

PIP 背側受到撞擊、強迫屈曲或切割可傷及中央腱束。早期仍可能部分伸直，若漏診，外側腱束掌移後可逐漸形成 PIP 屈曲與 DIP 過伸的 boutonniere 變形。

## 鑑別診斷

背側壓痛、PIP 主動伸直困難與 Elson 結果可提高懷疑，但急性疼痛、部分撕裂及多重伸肌機制傷害可能產生模糊結果。早期外觀正常不能排除。

## 問診重點

1. 記錄撞擊、脫位或背側傷口，觀察 PIP 腫脹與休息姿勢。
2. 檢查主動 PIP 伸直落差、被動活動度及 DIP 動作。
3. 在疼痛容許且未疑骨折／脫位時執行[[特殊檢查－Elson Test]]。
4. 檢查側副韌帶、感覺、指端灌流與 X 光，排除撕脫骨折或關節不對位。
5. 高度懷疑時以合適位置保護 PIP 並安排手外科／手治療評估。

## 影像與轉介

- 開放傷、PIP 脫位後無法穩定、神經血管異常或突然加重伸直落差需快速轉介。
- 不以反覆強力屈伸測試觀察是否「會自己鬆開」。
