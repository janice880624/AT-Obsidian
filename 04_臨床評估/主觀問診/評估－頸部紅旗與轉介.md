# 評估－頸部紅旗與轉介

![[assets/special-tests/頸部初步評估流程.svg]]

## 立即停止現場測試並啟動相應流程

- 重大或高風險創傷、頸椎中線壓痛、明顯畸形。
- 新發或進行性肢體無力、感覺喪失、雙側症狀。
- 步態異常、手部靈巧度下降、反射明顯亢進等疑似脊髓徵象。
- 意識狀態改變、無法可靠溝通或合併嚴重頭部傷害。
- 突發且異常的頭頸痛，伴隨複視、說話或吞嚥困難、共濟失調、顏面／肢體神經症狀等疑似血管或中樞表現。
- 發燒、免疫抑制、癌症史、不明體重下降、持續夜間痛等系統性警訊。

## 防護員決策原則

1. 先處理生命威脅與頸椎固定需求。
2. 紅旗不是單一清單勾選即可排除；需結合機轉、時間進程及客觀檢查。
3. Canadian C-Spine Rule 只適用於其原研究定義的清醒、穩定成人創傷族群，且應由受過訓練者依當地規範使用。
4. 不以傳統「椎動脈位置測試」單獨排除血管病理；採完整病史與臨床推理。
