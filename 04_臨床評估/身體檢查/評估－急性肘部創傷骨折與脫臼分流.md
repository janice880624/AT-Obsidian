# 評估－急性肘部創傷骨折與脫臼分流

![[assets/assessment/急性肘部創傷分流流程.svg]]

## 臨床意義

急性肘痛先辨識威脅生命／肢體的問題，再保護疑似骨折脫臼、紀錄神經血管狀態並選擇影像。流程服務於分流，不取代醫師診斷或機構急救規範。

## 操作步驟

1. **主調查**：高能量機轉、頭頸／胸部、多重創傷與生命徵象。
2. **立即紅旗**：開放傷、皮膚受壓、明顯變形、脈搏／回填異常、進行性神經缺損。
3. **保護紀錄**：支托於最舒適位置；記錄復位／固定前的循環與神經功能。
4. **局部檢查**：最低必要程度檢查遠端肱骨、鷹嘴、橈骨頭及腕／肩合併傷。
5. **影像**：急性創傷通常先做 X 光；陰性或不確定但仍高度懷疑時，依骨、肌腱／韌帶或感染情境安排 CT、MRI、超音波或追蹤影像。

## 判讀

能部分伸肘、外觀正常或單張陰性 X 光都不能一律排除骨折。影像選擇依病史、檢查、初始 X 光與疑似組織，不是所有肘痛都直接做 MRI。

## 禁忌／紅旗

不可在場邊反覆做壓力測試、牽拉或未授權復位。無脈、肢端冰冷、快速腫脹、開放傷或神經功能惡化需立即急診。
