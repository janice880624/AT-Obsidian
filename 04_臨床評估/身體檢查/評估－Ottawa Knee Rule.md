# Ottawa Knee Rule

## 用途

用於成人急性膝傷後判斷是否需要膝部 X 光。它是骨折影像分流規則，不是「膝傷安全規則」，也不排除韌帶、半月板、肌腱、軟骨或血管神經損傷。

## 五項條件

任一項符合即建議依醫療流程安排 X 光：

1. 年齡 55 歲以上。
2. 腓骨頭壓痛。
3. 只有髕骨壓痛、沒有其他膝部骨性壓痛。
4. 無法屈膝至 90°。
5. 受傷當下與評估時皆無法負重走四步（每腳兩步，即使跛行也算步數）。

## 操作與紀錄

先確認適用族群與受傷時間，逐項記錄「是／否／無法評估」。若疼痛、溝通、醉酒、多重創傷、明顯變形或其他因素使規則不可靠，直接依專業流程轉介，不應硬套。

## 判讀限制

原始推導研究 1,047 名成人，規則敏感度 1.00、特異度 0.54；外部研究並非全部複製相同結果。陰性只代表骨折機率降低，不能取代完整檢查。兒童、孕婦或特殊族群應依當地指引與醫療判斷。

## 紅旗優先

疑似膝脫臼、開放傷、神經血管異常、腔室症候群、感染或伸膝機轉斷裂時，不等待規則或 X 光結果才處置。
