# 評估－手指伸肌腱中央化與 PIP 穩定檢查

## 檢查目的

系統檢查 MCP 伸肌腱中央化、PIP 掌側板與側副穩定，並辨識需影像或手外科的骨折脫位、肌腱與神經血管問題。

## 檢查前準備

移除戒指，確認機轉與 X 光需求，暴露雙手比較；變形、開放傷或灌流異常不做挑釁。

## 觀察

手指串列、旋轉、MCP 背側腫脹、伸肌腱偏移、PIP 對位、瘀青與 resting posture。

## 觸診

輕觸 MCP 矢狀帶與伸肌腱、PIP 掌側板與兩側、骨性標誌及腱走向。

## 關節活動度

記錄 MCP／PIP／DIP 主被動屈伸、是否可啟動伸直、固定相鄰關節後的差異與終末感。

## 肌力與等長收縮

先低力測伸指、屈指與側向穩定；急性骨傷、斷裂或明顯不穩疑慮不做最大阻力。

## 神經血管檢查

毛細回填、皮溫、指側感覺與正中／尺／橈神經運動；緊戒指或快速腫脹需立即處理。

## 特殊檢查

安全時動態觀察伸肌腱中央化與 PIP 輕度側向比較；Elson 等測試依假設使用，不能單獨排除複合傷。

## 功能性測試

由輕觸、捏紙、抓握到球類或工具任務；急性期不以疼痛硬做全力握持。

## 判讀與臨床推論

無法啟動 MCP 伸直、動態腱偏移支持矢狀帶問題；PIP 掌側痛與過伸機轉支持掌側板假設，均需排除骨折脫位。

## 停止與轉介條件

變形、旋轉錯位、灌流差、開放傷、主動屈伸喪失、不可復位、快速神經惡化或測試造成失控。

## 紀錄重點

受傷指、角度、主被動差、腱位置、穩定方向、神經血管、影像需求、保護方式與追蹤日期。
