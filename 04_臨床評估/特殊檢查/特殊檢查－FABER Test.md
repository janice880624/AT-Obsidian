# 特殊檢查－FABER Test

## 檢查目的

FABER（屈曲、外展、外旋）用於觀察髖活動與誘發症狀；腹股溝、外側髖或後骨盆疼痛可能代表不同假設。它不能單獨診斷關節唇、薦髂關節或 FAI 症候群。

## 操作方法

1. 個案仰躺，將測試側腳踝置於對側大腿，形成「4」字。
2. 穩定對側骨盆，讓測試側膝在可耐受範圍下降。
3. 記錄活動範圍、終末感、疼痛位置與熟悉度；左右比較但不追求壓到床面。
4. 需要時搭配其他髖、腰椎或骨盆測試修正假設。

- 個案姿勢：依上述操作內容與個案耐受度設定。
- 操作者位置：依上述操作內容設定並確保可穩定控制。
- 固定位置：固定近端並避免非目標動作代償。
- 施力方向：依上述操作步驟施力。
- 比較方式：必要時與健側比較，並記錄疼痛、防禦與終末感。

## 陽性結果

以熟悉症狀重現為主要判讀，而不是單純膝離床距離。測試可牽涉多個結構，診斷準確度會因目標病變、族群與陽性定義大幅變動。
