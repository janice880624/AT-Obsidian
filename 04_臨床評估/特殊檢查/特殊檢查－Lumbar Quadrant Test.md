# 特殊檢查－Lumbar Quadrant Test

## 檢查目的

以腰椎伸展、側彎與旋轉組合觀察熟悉症狀，用於形成機械負荷假設；不是小面關節確診工具。

## 操作方法

1. 個案姿勢：站姿或坐姿，先確認平衡與紅旗。
2. 操作者位置：站在個案側後方並提供保護。
3. 固定位置：骨盆僅在需要比較時溫和控制，不強迫末端。
4. 施力方向：主動或輕度引導至伸展、同側側彎與旋轉組合。
5. 比較方式：比較側別、單方向動作與熟悉症狀，不以活動幅度或喀聲判定。

## 陽性結果

重現熟悉局部腰痛或腿部症狀；局部痛、放射痛與一般緊繃需分開記錄，不能視為同一陽性。

## 臨床解釋

可能增加小面／椎間孔或其他後方結構受負荷的假設，但系統性回顧顯示 Kemp test 對小面痛診斷準確度差。

## 注意事項與常見錯誤

紅旗、急性創傷、明顯骨質脆弱或進行性神經症狀不做；避免用力壓到末端、把疼痛視為「關節卡住」或依喀聲矯正。

## 診斷價值

- 敏感度：跨研究表現不足，不能可靠排除小面痛。
- 特異度：有限，其他後方結構與椎間孔症狀亦可陽性。
- 陽性概似比：系統性回顧未支持有足夠的單獨確診效用。
- 陰性概似比：陰性不足以排除。
- 研究族群：慢性腰痛與接受介入參照標準者；不可直接外推所有運動員。

## 搭配檢查

搭配[[評估－成人運動員持續性胸腰痛安全分流]]、完整神經學、方向性動作、髖檢查與功能負荷；參見[[傷害－腰椎小面關節相關疼痛]]。
