# 特殊檢查－Prone Instability Test

## 臨床意義

Prone Instability Test 嘗試辨識腰痛是否在軀幹肌活化後減少，可作為運動反應的線索；其診斷準確度與重現性有限，不能單獨證明「節段不穩定」或決定治療。

## 操作步驟

1. 先排除創傷、骨折、嚴重神經與其他紅旗。
2. 俯臥於床，軀幹在床面、雙腿自然垂於床緣，足部接地。
3. 檢查者對疑似節段施加輕柔後前壓力並記錄熟悉疼痛。
4. 請個案抬腿離地以活化背伸肌，再於相同位置與力量重測。
5. 記錄疼痛是否減少、相同或增加，以及施力節段與症狀品質。

## 判讀

抬腿後熟悉疼痛明顯減少常被視為陽性，但應只作為負荷與運動處方線索。陰性不能排除腰椎問題，陽性也不能確診機械性不穩定。

## 禁忌／紅旗

- 急性高能量創傷、疑骨折、妊娠俯臥不適、腹部病理或神經惡化時不做。
- 不反覆重壓或以疼痛強度作為唯一結果。
