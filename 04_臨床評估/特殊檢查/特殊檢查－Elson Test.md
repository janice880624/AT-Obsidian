# 特殊檢查－Elson Test

## 臨床意義

Elson test 用於評估 PIP 中央腱束完整性，適合放在機轉、壓痛、主動伸直與影像之後。它可提供線索，但急性疼痛、部分撕裂與其他伸肌傷害會限制判讀，不能單獨確診。

## 操作步驟

1. 排除明顯骨折、未復位脫位、開放傷與神經血管異常。
2. 將受測 PIP 屈曲約 90 度並讓中節指骨靠在桌緣，DIP 保持自由。
3. 請個案嘗試伸直 PIP，檢查者提供輕柔阻力。
4. 同時觸察／觀察 PIP 伸展力量及 DIP 是否變得僵硬伸直。
5. 與健側同指比較並記錄疼痛、力量與 DIP 質感；只做最少必要次數。

## 判讀

- 可疑陽性：PIP 伸展力量減弱，且 DIP 由原本較鬆的屈曲轉為僵硬伸直。
- 陰性不能排除急性或部分中央腱束損傷；如果機轉與壓痛高度相符，仍應保護並轉介。
- 不報告孤立的陽性／陰性；應附上測試條件與其他臨床發現。

## 禁忌／紅旗

- 未排除骨折、關節不對位、開放傷或劇痛時不施加阻力。
- 測試後疼痛或伸直落差惡化應停止並重新分流。
