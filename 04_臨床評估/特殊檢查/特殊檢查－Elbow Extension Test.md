# 特殊檢查－Elbow Extension Test

## 檢查目的

以能否完全伸肘協助急性肘傷的骨折風險判斷與影像決策，不作為獨立排除工具。

## 操作方法

1. 個案姿勢：坐或站，雙肩屈曲約 90°、前臂旋後。
2. 操作者位置：前側觀察並保護。
3. 固定位置：不需外力固定，保持上臂高度一致。
4. 施力方向：請個案主動伸直兩肘，不施加被動終末壓力。
5. 比較方式：與未傷側比較是否能達完整伸直及熟悉痛。

## 陽性結果

傷側不能主動完全伸直或明顯疼痛受限；陽性需考慮 X 光，不能指出骨折位置。

## 臨床解釋

多中心研究顯示完全伸直可降低骨折機率，但仍可能漏掉少數骨折；兒童與高風險機轉更需保守判斷。

## 注意事項與常見錯誤

不施被動壓力、不在畸形或高能量傷反覆測試；既往伸直限制、疼痛容忍與雙側差異會影響。

## 診斷價值

- 敏感度：成人約 96.8%，兒童約 94.6%。
- 特異度：成人約 48.5%，兒童約 55.6%。
- 陽性概似比：約 1.9–2.1，僅小幅提高機率。
- 陰性概似比：約 0.07–0.10，但不能取代高風險臨床判斷。
- 研究族群：英國五個急診的成人與兒童急性肘傷。
