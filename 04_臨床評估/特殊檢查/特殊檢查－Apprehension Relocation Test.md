# 特殊檢查－Apprehension Relocation Test

## 臨床意義

用於評估前向肩關節不穩定。重點是重現熟悉的「不穩或快脫臼感」，而非單純前肩疼痛。

## 操作步驟

1. 個案仰躺，肩接近 90° 外展、肘屈曲；操作者控制肱骨與前臂。
2. 緩慢增加外旋，可加極輕且可控的前向力量，持續詢問症狀。
3. 若出現熟悉的 apprehension，停止增加外旋。
4. Relocation 階段對肱骨頭施後向支持；觀察不穩感是否減輕。
5. 紀錄角度、疼痛或不穩感、支持後變化及左右差異。

## 陽性與判讀

Apprehension 階段出現熟悉恐懼／不穩感，且後向支持使其緩解，較支持前向不穩定。只有疼痛屬非典型結果，需考慮其他來源。

原始研究顯示 surprise／release test 特異度可很高，但敏感度有限；測試組合可提高確認價值，不能單獨排除不穩定。

## 禁忌

急性疑似脫臼、近期骨折、術後保護期、高度易刺激、明顯神經血管異常，或個案拒絕時不做。禁止突然 release 製造驚嚇或脫臼風險。
