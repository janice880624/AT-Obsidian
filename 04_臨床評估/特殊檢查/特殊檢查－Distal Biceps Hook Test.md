# 特殊檢查－Distal Biceps Hook Test

## 臨床意義

Hook test 用於評估遠端肱二頭肌腱是否可在肘窩外側被勾住，對完全斷裂有臨床價值；部分撕裂、疼痛或解剖差異會降低其排除能力。

## 操作步驟

1. 受測者肩部放鬆、肘屈約 90°並主動前臂旋後。
2. 檢查者由外側將食指輕柔滑入肌腱深面，嘗試勾住繃緊腱體。
3. 比較健側並記錄是否能勾住、腱體連續感及疼痛。
4. 若無法明確判讀，停止反覆操作並以其他檢查與影像確認。

## 判讀

無法勾住連續腱體支持完全斷裂；能勾住不代表沒有部分撕裂。2022 研究顯示標準化檢查組合可提高診斷效率，但結果依族群與參考標準而異。

## 禁忌／紅旗

疑似骨折脫臼、開放傷、劇烈疼痛或神經血管異常時不做。不可把陰性 Hook test 當作排除部分撕裂的依據。
