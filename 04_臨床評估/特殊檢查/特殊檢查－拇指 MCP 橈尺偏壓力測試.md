# 特殊檢查－拇指 MCP 橈尺偏壓力測試

## 檢查目的

比較拇指 MCP 側向鬆弛與終點，協助辨識橈側或尺側副韌帶高階損傷；不可單獨確診。

## 操作方法

1. 個案姿勢：前臂支撐、拇指放鬆。
2. 操作者位置：一手固定第一掌骨、一手握近節指骨。
3. 固定位置：穩定 MCP 近端並修正明顯半脫位。
4. 施力方向：先伸直、再約 30° 屈曲，緩慢施加橈偏與尺偏壓力。
5. 比較方式：比較對側、角度、疼痛與是否有明確終點。

![[assets/special-tests/手腕與手第七輪拇指 MCP 壓力測試.svg]]

## 陽性結果

熟悉疼痛加鬆弛增加或缺乏明確終點；RCL 完全傷常見尺偏鬆弛。

## 臨床解釋

伸直同時評估副韌帶／掌板，約 30° 屈曲較偏本體束；疼痛防衛、個體差與半脫位會影響。

## 注意事項與常見錯誤

先排骨折，緩慢施力且不反覆追求最大角度；不要把單一度數跨個體套用。

## 診斷價值

- 敏感度：尚無一致高品質數值。
- 特異度：尚無一致高品質數值。
- 陽性概似比：未建立。
- 陰性概似比：未建立。
- 研究族群：多為病例系列、影像／術中比較與生物力學研究。

## 搭配檢查

拇指 X 光、關節對位、撕脫骨折、必要超音波／MRI及手外科評估。
