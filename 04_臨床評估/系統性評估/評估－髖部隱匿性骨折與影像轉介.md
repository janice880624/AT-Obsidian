# 評估－髖部隱匿性骨折與影像轉介

## 臨床意義

跌倒、直接撞擊或高負荷後若持續深層髖痛與承重困難，即使初次 X 光陰性，仍可能有股骨近端、髖臼或骨盆隱匿性骨折。延誤承重限制與進一步影像可能造成移位或併發症。

## 評估／操作步驟

1. 記錄受傷機轉、骨質風險、疼痛位置、夜痛及承重能力。
2. 觀察肢位、瘀青與短縮旋轉；完成遠端神經血管檢查。
3. 有骨折疑慮時避免跳躍、單腳蹲與反覆終末角度測試。
4. 初始通常以髖與骨盆 X 光評估；高度疑慮但 X 光陰性時轉介進一步影像。

## 判讀

持續無法承重、骨性壓痛、被動旋轉痛或高風險機轉，使骨折前測機率上升。依 ACR，疑似外傷性骨折而 X 光陰性或不確定時，MRI 或無對比 CT 通常適合；MRI亦可偵測骨髓水腫與非移位骨折。單一臨床測試不能排除骨折。

## 禁忌／紅旗

- 懷疑骨折時先保護承重，不以「走得動」作為排除依據。
- 畸形、神經血管異常、循環不穩或高能量創傷需急診處置。
- 不因止痛後改善或初次 X 光陰性而強迫回場。
