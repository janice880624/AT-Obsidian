# 評估－疑似膝周骨腫瘤影像與轉介流程

## 評估目的

建立疑似原發骨腫瘤的影像與轉介順序，避免未規劃活檢污染未來手術路徑。

## 適用情境

持續或夜間骨痛、可觸骨性腫塊、病理性骨折或 X 光可疑病灶。

## 評估流程

1. 初步安全與紅旗篩檢：先排除病理性骨折、神經血管與全身急症。
2. 主觀問診：確認疼痛／腫塊進展、癌症與感染背景。
3. 客觀檢查：輕柔定位、功能與神經血管基線。
4. 功能與負荷測試：病灶未明前不做跳躍或最大負荷。
5. 再評估：追蹤 X 光、MRI／CT、肉瘤 MDT 與活檢結果。

## 判讀框架

兩方向 X 光為起始；正常 X 光不完全排除。可疑或持續者以 MRI／CT 評估範圍，確診需專科規劃病理。

## 紅旗與轉介

快速腫大、病理性骨折、侵襲性影像、無法負重或神經血管異常急迫轉介。

## 處置與追蹤

保護負重並轉骨腫瘤中心；未與肉瘤團隊討論前不自行穿刺或切除。

## 紀錄最小集合

時間軸、腫塊尺寸、神經血管、影像日期與結果、保護措施、轉介單位與時限。

## 常見錯誤與限制

正常 X 光即結案、把 MRI 當病理、先切後送、對病灶按摩或以運動反應判定良性。
