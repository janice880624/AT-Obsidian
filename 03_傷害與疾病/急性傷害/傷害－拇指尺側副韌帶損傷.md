# 傷害－拇指尺側副韌帶損傷

## 定義

拇指掌指關節（MCP）突然外翻可傷及尺側副韌帶（UCL），常見於雪杖、球類或跌倒。完全撕裂合併 Stener lesion 時韌帶可能被拇收肌腱膜阻隔而無法自然回位，延遲處理會影響捏力與關節穩定。

## 鑑別診斷

明顯鬆弛且缺乏清楚終點提高完全撕裂疑慮，但疼痛防衛、測試角度、個體差異與骨折會影響結果。不要用單一角度差或單次壓力測試確診。

## 問診重點

1. 記錄外翻機轉、疼痛、腫脹及捏物無力。
2. 觸診 MCP 尺側與近端是否有局部腫塊；先檢查感覺與灌流。
3. 若骨折風險低且受過訓練，在 MCP 伸直及輕度屈曲位施加非常輕柔外翻壓力，比較終點感；疼痛明顯即停止。
4. 懷疑撕脫骨折先做 X 光；超音波或 MRI 用於韌帶與 Stener lesion 評估時由專科安排。

## 影像與轉介

- 骨性壓痛、明顯變形、無終點、可觸及腫塊或神經血管異常需快速手外科評估。
- 疑似骨折、急性劇痛或不熟悉技術時，不做強力壓力測試。
