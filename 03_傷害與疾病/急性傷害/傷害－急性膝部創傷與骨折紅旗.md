# 急性膝部創傷與骨折紅旗

## 臨床意義

急性扭轉、直接撞擊、落地或高能量創傷可同時造成骨折、脫臼、韌帶、半月板與骨軟骨損傷。場邊優先工作是辨認威脅肢體或需要影像的狀況，不是立即以大量特殊檢查命名組織。

![[assets/assessment/膝部急性創傷分流流程.svg]]

## 初步評估步驟

1. 確認安全、生命徵象與高能量機轉；暴力創傷先依機構急救流程。
2. 看：變形、開放傷口、迅速腫脹、皮膚顏色與髕骨位置。
3. 摸：髕骨、腓骨頭、股骨髁、脛骨平台與關節線；勿反覆壓迫可疑骨折。
4. 神經血管：足背／脛後動脈、微血管回填、皮溫、腓總神經與脛神經運動感覺；記錄時間並反覆比較。
5. 功能：若無明顯禁忌，確認屈膝是否達 90°及能否安全走四步；以 [[評估－Ottawa Knee Rule]] 協助 X 光決策。

## 判讀與處置

- 疑似膝脫臼即使已自行復位，仍可能有膕動脈損傷；正常單次脈搏不能完全排除，需緊急醫療評估與連續神經血管監測。
- Ottawa Knee Rule 用於篩選急性膝傷是否需要 X 光，不排除 ACL、半月板或軟骨傷。
- X 光陰性但持續不能負重、局部骨痛、巨大關節積血或機械性卡住，仍需轉介；後續影像依臨床問題選擇。

## 立即轉介紅旗

- 開放傷、明顯變形、疑似脫臼或髕骨無法復位。
- 足部脈搏減弱／不對稱、蒼白冰冷、進行性感覺或肌力異常。
- 疑似腔室症候群：疼痛遠超預期、被動伸展痛、緊繃腫脹或神經症狀。
- 發燒伴紅熱腫、非創傷性巨大腫脹、免疫抑制或全身不適。

## 不應做的事

不可在疑似骨折、脫臼或神經血管受損時強力活動、負重測試或反覆施作韌帶壓力測試；不可用冰敷後疼痛下降取代再評估。
