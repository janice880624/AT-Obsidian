# 傷害－伸肌腱矢狀帶損傷

## 定義

伸肌腱矢狀帶損傷俗稱 boxer knuckle，可使伸肌腱在掌指關節屈曲時偏移、半脫位或脫位。臨床判斷須整合病史、完整檢查、影像適應症與追蹤，單一特殊檢查不能確診。

## 受傷機轉

拳擊或直接撞擊掌指關節背側，也可由低能量扭轉或慢性滑膜病變造成；中指橈側矢狀帶常受累。

## 常見症狀與徵象

MCP 背側疼痛腫脹、屈伸時彈跳，無法由屈曲位主動啟動伸直但被動置於伸直後可能可維持。

## 危險因子

拳擊／格鬥、反覆直接撞擊、延遲辨識、類風濕或既往 MCP 手術；單純背側痛不代表伸肌腱已脫位。

## 鑑別診斷

MCP 骨折、伸肌腱裂傷、側副韌帶傷、腱鞘炎、trigger finger 與炎性關節病。

## 問診重點

確認創傷或負荷起始、受力方向、慣用手、腫瘀與卡彈、麻刺無力、夜間症狀、既往骨折手術，以及握持、撐地、球拍、單車或工作需求。

## 觀察與觸診

觀察 MCP 屈伸時伸肌腱是否中央化，觸診矢狀帶與腱滑動；急性腫痛不反覆製造脫位。

## 關節活動度與肌力

先比較主被動腕屈伸、橈尺偏、前臂旋轉與手指動作，再做低負荷等長及握捏；疑骨折、脫位、肌腱斷裂或神經缺損時避免最大阻力。

## 特殊檢查

依臨床假設選擇穩定性、肌腱或神經測試，記錄症狀位置與品質；任何陽性只調整機率，不取代影像、電生理、手外科或整體臨床分類。

## 影像與轉介

持續彈跳、無法啟動伸直、開放傷或不明不穩需手外科；動態超音波可顯示腱偏移，X 光排除骨傷。

## 急性處置

停止撞擊與強力握拳，保護 MCP 伸展／相對伸展位；開放傷、旋轉變形或神經血管異常急迫處理。

## 復健原則

急性閉鎖性損傷可依專科採相對運動或 MCP 保護並受控活動；慢性不穩或保守失敗可能需修復／重建。

## 回場條件

無彈跳或伸直遲滯，屈伸與握拳控制完整，逐步完成抓握、推撐與撞擊需求且隔日穩定。
