# 傷害－骨盆骨骺撕脫骨折

## 定義

青少年在衝刺、踢球、跳躍或劈腿時突然強力收縮，可於 ASIS、AIIS、坐骨結節或髂嵴發生撕脫骨折，易被誤認肌肉拉傷。位移、疼痛與運動需求會影響處置及回場。

## 鑑別診斷

典型機轉、骨骺壓痛與影像共同判斷；正常初期 X 光不完全排除未骨化骨骺或微小撕脫。單一力量測試不能確診。

## 問診重點

1. 記錄爆裂感、急性局部痛、跛行及動作機轉。
2. 以一指定位骨性壓痛，觀察瘀青與步態。
3. 輕柔測相關肌群等長收縮與伸展，不反覆誘痛。
4. 取得骨盆 X 光；高度懷疑或複雜型態時由專科安排 MRI／CT。

## 影像與轉介

- 無法負重、明顯位移、持續劇痛、神經症狀或疑急腹症需快速轉介。
- 不在未排除骨折前做最大衝刺、踢擊或拉伸。
