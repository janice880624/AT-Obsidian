# 傷害－股骨頸骨應力傷

## 臨床意義

股骨頸骨應力傷從骨髓水腫、應力反應到骨折形成連續光譜；張力側或已移位病灶可能進展並造成缺血性壞死等嚴重後果。早期 X 光可能正常，因此「能走」或陰性 X 光不能安全排除。

## 評估與現場處置

1. 問近期跑量／衝擊量增加、恢復、能量攝取、月經或內分泌、既往骨應力傷與骨密度風險。
2. 注意逐漸加重的負重腹股溝或前髖痛、跛行、夜間或休息痛；避免反覆單腳跳測試。
3. 高度懷疑時立即停止跑跳與負重，使用輔具並安排當日醫療評估。
4. 影像通常先 X 光；持續懷疑且 X 光陰性時，MRI 是重要的進一步檢查，由醫療端決定。

## 判讀

疼痛性髖活動或負重測試只能提高懷疑，不能判定壓縮側／張力側、骨折線長度或穩定性。這些分類需影像與專科評估。

## 禁忌／紅旗

疑似個案禁止繼續跑、跳、負重回場測試或強力關節鬆動。突然劇痛、無法負重、肢體短縮／旋轉或神經血管異常須緊急處置。

## 回場

依影像分型、是否手術、骨癒合與風險因子個別化；須取得醫療許可，再由無痛日常負重進展至力量、跑跳與專項，不能只以固定週數決定。
