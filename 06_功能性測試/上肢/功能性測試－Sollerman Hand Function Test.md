# 功能性測試－Sollerman Hand Function Test

## 測試目的

以 20 項日常活動與八種常見握型，標準化觀察單手及雙手的任務完成品質與時間。

## 適用對象

需要量化整體手功能、握型與活動限制者；急性感染、未穩定骨傷或醫療限制未解除者不適用。

## 器材與場地

原始標準化測試箱及指定物件、桌椅、計時器與評分表；若器材或任務被修改，必須明確標註版本。

## 操作流程

依原始順序完成鑰匙、硬幣、螺帽、螺絲起子、罐蓋、鈕扣、書寫等 20 項活動，遵守單手／雙手規定並記錄代償。

## 計分方式

每項 0–4 分，依是否完成、時間、困難與使用規定握型計分，總分最高 80；同時記錄疼痛、協助與停止原因。

## 判讀方式

與同一人前測、受影響側、適切族群資料及實際任務需求整合；總分相同也可能有不同握型缺損。

## 測試品質與限制

原始研究以四肢癱瘓與手功能重建族群為主；器材、學習、文化任務、疼痛與雙手代償影響結果，並非運動回場單一門檻。

## 停止條件

紅熱腫脹或感染疑慮、骨性銳痛、手冷、麻弱增加、物件控制危險、醫療限制或個案要求停止。
