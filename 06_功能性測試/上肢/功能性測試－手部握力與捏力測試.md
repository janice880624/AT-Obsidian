# 功能性測試－手部握力與捏力測試

## 臨床意義

握力與捏力可量化整體手部力量及症狀反應，適合追蹤復健與回場準備。結果會受器材、握把設定、姿勢、指令、慣用側、疼痛與努力程度影響，必須標準化才可比較。

## 操作步驟

1. 確認組織已允許施力，記錄器材、握把位置、慣用手與疼痛。
2. 坐姿肩內收中立、肘約 90 度、前臂中立、腕接近中立；每次沿用相同設定。
3. 握力計做 1 次次最大熟悉後，完成 3 次穩定最大等長收縮，次間充分休息。
4. 依需求測 key、tip、three-jaw chuck pinch；各型態同樣記錄 3 次。
5. 使用三次平均並記錄症狀、代償及測後／隔日反應。

## 判讀

- 優先與個人基準比較；對側比較需考慮慣用側與雙側受訓差異。
- 三次平均通常比單次最高值更可靠，但仍需考量最小可偵測變化及器材誤差。
- 力量接近對側不代表接球、撞擊或承重能力已恢復；需和項目任務整合。

## 禁忌／紅旗

- 未癒合骨折、急性韌帶不穩定、腱修復限制、劇痛或神經血管異常不做最大測試。
- 若出現突然失力、爆裂感、麻木或腫脹加劇，立即停止並重新評估。
