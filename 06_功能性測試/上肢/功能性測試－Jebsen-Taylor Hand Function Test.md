# 功能性測試－Jebsen-Taylor Hand Function Test

## 測試目的

以七項模擬日常任務的完成時間評估單手精細與粗大功能，作為追蹤及任務分析的一部分。

## 適用對象

需要量化寫字、翻卡、拾小物、模擬進食、堆疊與搬移輕重物的個案；並非運動專項回場的單一門檻。

## 器材與場地

標準化桌椅、秒錶、紙筆、卡片、小物件、模擬進食工具、棋子與輕重罐；器材尺寸與順序需一致。

## 操作流程

先說明與示範，依標準順序分別測非慣用手與慣用手；每項計時並記錄錯誤、代償、疼痛與是否練習。

## 計分方式

各分測驗記錄完成秒數，通常分項呈現；時間越短代表任務速度較快，不宜任意合併不同版本或器材。

## 判讀方式

與同一人前測、對側及適切常模比較，結合動作品質、疼痛與實際需求；改善可能受練習效應影響。

## 測試品質與限制

版本、器材、順序與熟悉度影響結果；寫字受語言教育影響，且測試不直接量化最大握力或運動碰撞耐受。

## 停止條件

疼痛快速增加、麻弱、失去物件控制、明顯代償、醫療限制或任何神經血管警訊。
