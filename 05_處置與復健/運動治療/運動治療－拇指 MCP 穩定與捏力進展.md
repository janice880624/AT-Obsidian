# 運動治療－拇指 MCP 穩定與捏力進展

## 訓練目的

在韌帶癒合與醫療限制內，逐步恢復拇指活動、側向穩定、對掌與捏握。

## 適用階段

骨折與高階不穩定已排除或處理，支具與活動範圍限制清楚者。

## 起始姿勢

前臂支撐、拇指 MCP 中立，從無痛對掌與低負荷等長開始。

## 動作步驟

1. 溫和屈伸、外展與對掌。
2. 多方向低負荷等長。
3. 軟物捏握與功能抓取。
4. 進展球、球拍、車把與接觸任務。

## 劑量

- 組數：2–4 組。
- 次數／時間：6–15 次或 15–30 秒。
- 強度：RPE 2–5 起，依穩定性進展。
- 頻率：每週 3–5 次，較重捏力間保留恢復。

## 動作品質提示

MCP 保持中立，不以關節尺偏或過伸換取力量；先準確再加阻力。

## 常見代償

過早側向壓力、只練拇指不整合腕手、忽略支具與手外科限制。

## 退階方式

降低阻力、縮短時間、改大物件抓握或使用支具。

## 進階方式

增加阻力、速度、持續時間、物件精細度及運動特定握持。

## 停止條件

鬆脫感、無終點感、銳痛、腫脹、麻木、變形或隔日明顯惡化。
