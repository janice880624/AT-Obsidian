# 防護員知識系統

## 系統簡介

防護員知識系統是一套以運動防護實務為核心建立的 Obsidian 知識庫，目的在整合人體解剖、運動傷害評估、特殊檢查、貼紮技術、運動治療與回場測試等資訊，協助運動防護相關人員快速查找、理解並建立各項知識之間的關聯。

本系統不只用資料夾分類資料，也透過 Obsidian 雙向連結，將身體區域、解剖構造、傷害、評估方法與處置方式相互連接，形成可持續擴充的運動防護知識網絡。

## 系統內容

本知識系統主要包含：

* 骨骼、關節、肌肉、韌帶與神經解剖
* 各身體區域的常見運動傷害
* 主觀問診、觸診及神經學評估
* 關節活動度與肌力測試
* 特殊檢查及其診斷價值
* 肌內效貼布與運動貼紮
* 運動治療與復健進階方式
* 功能性測試與回場評估
* 急性傷害處置及轉介警訊
* 相關研究、臨床指引與文獻筆記

## 知識架構

系統以身體區域作為主要入口：

[[頭頸]]｜[[肩部]]｜[[肘部]]｜[[手腕與手]]｜[[胸腰椎]]｜[[骨盆與髖]]｜[[膝部]]｜[[足踝]]

每個身體區域皆會逐步建立以下臨床知識路徑：

> 解剖構造 → 常見傷害 → 臨床評估 → 特殊檢查 → 處置與運動治療 → 功能及回場評估

例如，在頸椎筆記中，可以進一步連結至相關肌肉、頸神經根、頸椎扭傷、神經根病變、特殊檢查及紅旗轉介原則，使不同類型的資訊不再是彼此分離的筆記。

## 筆記設計原則

每篇筆記盡量包含：

* 統一的 YAML 屬性與標籤
* 解剖或臨床核心概念
* 評估或操作步驟
* 陽性結果與判讀方式
* 禁忌、紅旗與安全注意事項
* 相關筆記的雙向連結
* 圖片或教學示意圖
* 研究、臨床指引或權威參考來源

特殊檢查不會只記錄操作方法，也會整理敏感度、特異度、概似比、研究族群及研究限制，避免依賴單一檢查結果做出診斷。

## 每日更新方式

系統會定期讀取 GitHub 中現有的 Vault 結構，確認已完成的身體區域、章節及筆記，避免重複建立相同內容。

每日知識包預計包含：

* 5 篇核心筆記
* 10 篇直接相關筆記
* 1～30 張必要的圖片或教學示意圖
* 當日內容索引
* 圖片來源與授權說明
* 需要更新的系統索引

每日內容會打包成 ZIP 並寄送至指定信箱。ZIP 解壓縮後即可合併至 Obsidian Vault，再由使用者同步至 GitHub，作為下一次內容盤點與生成的依據。

## 使用方式

1. 從身體區域或首頁索引進入主題。
2. 透過雙向連結延伸至解剖、傷害、評估及處置筆記。
3. 使用搜尋、標籤與關聯圖查看知識網絡。
4. 將尚未完成或需要查證的內容加入 [[待整理]]。
5. 新增內容時使用統一模板，以維持筆記格式與分類一致。
6. 定期檢查引用來源、內部連結及臨床資訊是否需要更新。

## 系統定位與限制

本系統定位為運動防護學習、臨床資料整理與決策思考的輔助工具，不能取代完整病史詢問、理學檢查、醫療影像、醫師診斷、緊急醫療處置或所屬機構的標準作業流程。

筆記中的特殊檢查、處置及回場資訊必須結合個案狀況、受傷機轉、神經血管狀態、研究證據及專業判斷使用。若出現重大創傷、進行性神經症狀或其他紅旗，應停止一般評估或處置，依緊急流程處理並轉介適當醫療人員。

## 系統目標

本系統希望逐步建立一套具有以下特性的運動防護知識庫：

* 快速查找
* 清楚分類
* 相互連結
* 具有實務價值
* 保留可靠來源
* 可以持續更新
* 能由解剖知識延伸至臨床應用

最終目標不是累積大量零散筆記，而是建立一套能協助防護員整合資訊、回顧知識並支持臨床思考的個人化知識系統。
